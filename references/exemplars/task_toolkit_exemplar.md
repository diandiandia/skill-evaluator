# PDF Processing Toolkit — 任务菜单型工具箱

本 Skill 封装了在无图形界面环境下处理 PDF 的全部常见操作。所有任务均为**原子化独立入口**，用户按需调用对应任务即可。

---

## 核心任务速查表 (Capability Index)

| 任务目标 | 核心操作模式 | 推荐工具链 / 机制 | 产出物契约 |
|:---|:---|:---|:---|
| **Task 1: 文本与大纲提取** | 结构化抽取 | `pdftotext -layout` 或 `pdfminer` | `.txt` / `.json` 结构化文本 |
| **Task 2: 表格精准识别** | 坐标与网格解析 | `pdfplumber` / 结构化提取 | `.csv` / `.xlsx` 表格文件 |
| **Task 3: 多文件合并与页面拆分**| 页面重组 | `pypdf` / `pdfunite` | 重组后的 `.pdf` 文件 |
| **Task 4: 页面高质量光栅化渲染**| 图像导出 | `pdftoppm -png -r 150` | 逐页高清 `.png` 序列 |

## 任务执行规约 (Tasks Specification)

### Task 1: 提取纯文本与大纲结构
1. **输入契约**：源 PDF 路径。
2. **前置探测**：检测 PDF 是否被加密或设有权限密码：
   - 若加密：提示用户提供密码，严禁尝试暴力破解。
3. **执行规约**：
   - 保持排版布局：优先保留多列排版的相对间距；
   - 提取目录大纲：若存在 Bookmarks，必须连同页码一并导出为索引。
4. **异常应对**：若提取结果全为空字符，判定为“扫描件/纯图片 PDF”，自动提示并切换至 OCR 工具通道。

### Task 2: 表格识别与导出
1. **输入契约**：源 PDF 路径、目标页码范围。
2. **执行规约**：
   - 优先识别有线表格（Explicit Lines）；若为无线表格，按文本流水平对齐间距聚类；
   - 检查合并单元格（Colspan / Rowspan），绝不能出现错列漂移。
3. **产物验收**：导出前自动校验行数与列数一致性，打印表格概览给用户预览。

### Task 3: 合并与拆分
1. **输入契约**：文件列表或截取区间（如 `1-5, 8, 12-end`）。
2. **幂等与安全**：
   - 输出文件名绝不能与任一输入源文件同名（避免覆盖原件）；
   - 输出完成后自动校验生成 PDF 的总页数是否等于预期页数之和。

---

## 通用边界与防误触守卫
- **大文件安全阈值**：单文件超过 100MB 或 1000 页时，必须提示用户分批处理，避免内存溢出；
- **清理临时产物**：中间生成的临时图片或缓存碎片必须在执行结束前自动清理，保持工作区整洁。
